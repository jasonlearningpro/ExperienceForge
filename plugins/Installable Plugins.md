# Installable Plugins for ExperienceForge

Plugins add extra features to ExperienceForge. They are separate from the app and have their own downloads.

## How to install one

1. Download the plugin's zip file from this folder. Don't unzip it.
2. In ExperienceForge, choose **Help → Plugins…** and open the **Install and safety** tab.
3. Choose **Install from a file…** and pick the zip.
4. On the **Installed** tab, tick **Use in this course** next to the plugin.

A plugin is a small program, so only install ones from someone you trust. Plugins run in a locked room inside ExperienceForge, but that isn't a hard wall.

## The plugins

| Plugin | Version | What it does |
|---|---|---|
| Course help panel | 1.0.0 | Adds a Help button to the course player. It opens a side panel listing the keys that work in the course and how to turn captions on or off. |
| Easy-to-read looks | 1.0.0 | Large-print player looks, extra-large caption styles with strong contrast, and an easy-to-read font choice. |
| 3D model viewer | 1.1.0 | Shows a 3D model (a .glb from Blender, or an .stl) on a screen, with a starting angle and color, and optional turning by dragging or by keys. Needs permission to read your course's files. |
| Objectives | 1.0.0 | Link each quiz question to the objective it tests, check that every objective is tested, and show learners a chart of how they did on each one. |
| Scoring modes | 1.0.0 | Two more ways to score a quiz: full credit only for a right answer on the first try, and partial credit for a partly right multiple-answer question. |

## Sharing a course that uses plugins

A course can carry its plugins inside its own file. In **Help → Plugins…**, tick **Carry it inside the course file**, then save. Whoever opens the course is asked before the plugins run.

## Versions

Each zip has the plugin's version in its name. A course remembers which version it uses.
